# 📝 To-Do Pro

Aplicação web simples e funcional para gerenciamento de tarefas diárias, desenvolvida com React.

## Tecnologias Usadas
- **React**
- **JavaScript (ES6+)**
- **CSS**

## Funcionalidades
- [x] Listagem de tarefas
- [x] Adicionar nova tarefa
- [x] Marcar tarefas como concluídas / reabrir
- [x] Excluir tarefas da lista
- [x] Contagem em tempo real de tarefas concluídas

## Como Executar o Projeto
1. Abra o terminal na pasta raiz do projeto (`todo-pro`).
2. Instale as dependências:
   ```bash
   npm install
3. Rode o programa com:
   ```bash
   npm run dev
